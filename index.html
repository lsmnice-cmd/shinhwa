🔔 접속 신청
이 명단은 Apps Script에 저장되어 직원 브라우저에서 바꿀 수 없습니다. 단, 실제 데이터 차단은 Firebase 규칙이 담당하므로, 아래 규칙에도 직원 UID를 넣어야 데이터가 보입니다.
Firebase 실시간DB 규칙 — 허용된 직원만 접속

승인만으로는 부족합니다. 아래 규칙을 Firebase 콘솔에 넣어야 실제 데이터가 보입니다.
(화면의 탭 숨김은 편의용이고, 진짜 차단은 이 규칙이 합니다)

① 복사 → ② 규칙 페이지 열기 → 붙여넣고 게시 
(위 버튼을 누르면 여기에 나옵니다)

Firebase 콘솔 → 빌드 → Realtime Database → 규칙 탭에 붙여넣고 게시하세요.

Firebase 콘솔 → 빌드 → Authentication → 로그인 방법에서 Google을 사용 설정하고, Settings → 승인된 도메인에 lsmnice-cmd.github.io를 추가하세요.

카톡 발주방 붙여넣기

단톡방 내용을 그대로 복사해 붙여넣으세요. 인사말·잡담은 AI가 걸러내고, 단가는 그대로 보존합니다. 같은 내용은 중복 저장되지 않습니다.
메시지에 날짜(7.7, 06.30 등)가 있으면 그 날짜가 우선 적용됩니다.
카톡 전체를 붙여넣어도 됩니다 — 날짜별로 자동 분리 처리합니다.
각 품목 옆에 작업스펙(세절·절단 방법)과 작업여부가 표시됩니다. 작업=손질 필요, 원물/박스=원물 그대로 출고.

📚 학습 대기

카톡에 나왔지만 아직 어떤 상품인지 모르는 것들입니다.
상품을 골라주시면 학습사전에 등록되어 다음부터 자동으로 붙습니다.
모르겠으면 [나중에]를 누르세요 — 다음에 다시 물어봅니다.

차량 · 작업여부 · 작업스펙 마스터

작업스펙은 어떻게 세절/절단하는지를 적는 칸입니다 (예: 2.5mm 세절, 8등분 커팅, 1kg씩 소분 진공). 모든 값은 구글 스프레드시트에 저장됩니다. 여기서 고치면 시트에 즉시 반영되고, 시트에서 고치면 새로고침 시 반영됩니다.
일괄 변경:
거래처 차량 상품명 작업여부 작업스펙 (세절·절단 방법)
＋ 품목 추가✕ 거래처 삭제 시트에서 대량 편집 후 [↻ 시트에서 새로고침]을 누르면 반영됩니다.
