Firebase 실시간DB 규칙 — 나만 접속 허용

Firebase 콘솔 → 빌드 → Realtime Database → 규칙 탭에 아래를 붙여넣고 게시. 내UID는 로그인 화면에 표시되는 값으로 바꾸세요.

{
  "rules": {
    ".read": "auth != null && auth.uid === '내UID'",
    ".write": "auth != null && auth.uid === '내UID'"
  }
}

여러 명 허용하려면: auth.uid === 'UID1' || auth.uid === 'UID2'

또한 Firebase 콘솔 → 빌드 → Authentication → 로그인 방법에서 Google을 사용 설정해야 합니다.

차량은 거래처 마스터에서 자동 매칭됩니다.
각 품목 옆에 작업스펙(세절·절단 방법)과 작업여부가 표시됩니다. 값은 ④ 마스터 또는 스프레드시트에서 입력합니다.

차량 · 작업여부 · 작업스펙 마스터

작업스펙은 어떻게 세절/절단하는지를 적는 칸입니다 (예: 2.5mm 세절, 8등분 커팅, 1kg씩 소분 진공). 모든 값은 구글 스프레드시트에 저장됩니다. 여기서 고치면 시트에 즉시 반영되고, 시트에서 고치면 새로고침 시 반영됩니다.
